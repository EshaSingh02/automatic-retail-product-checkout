# Source Notes

This repository was organized from the supplied project report and the three supplied notebooks:

- `notebooks/01_dino_training_inference.ipynb`
- `notebooks/02_vae_training_inference.ipynb`
- `notebooks/03_yolov8_finetuning_inference.ipynb`

The README separates reported experimental results from proposed future work. The repository does not include the RPC dataset or model checkpoints.

Some source scripts are cleaned, path-parameterized versions of the notebook workflows. The original notebooks are retained for provenance and should be treated as the closest record of the executed Kaggle workflow.
